## v1.0.0 · 面试准备 {#v1-0-0}

**待发布 · 这是本版范围说明，不是上线公告。** 正式版本以 [GitHub Releases](https://github.com/tianyi-zhang-02/cooking-agi/releases) 中的标签和提交为准。PR 合并、网站部署、创建 Release 是三个不同步骤。

这版想解决一个很实际的问题：笔记越来越多，看完导航还是不知道今天该学哪一页。我们把准备入口、练习路线和自己的阅读记录连起来，但你仍然可以只把网站当作参考资料。

### 这一版包括什么

- **一个收藏按钮、一个阅读面板**：笔记标题下点「收藏本页」；右上角「我的阅读」记下今天读了哪些笔记、读了几次，收藏、设置和备份也在这里。早先试做的独立学习台已并入这里，旧链接会跳回面试准备首页。
- **两种起点**：ML / LLM、后训练、推理系统、算法四个方向，各有起步和复习两组练习，共 8 组、24 个，放在[按计划学习](../interview/study-plan.md#routes)里。时间只供安排参考。
- **可带走的记录**：收藏、阅读记录和阅读位置共用一份 JSON 备份；导入是合并，同一条记录保留较新的一份。
- **技术世界树**：电力、芯片、软件、数据和模型各自怎么发展、在哪里交汇；按年代收录 143 个节点和 59 条有来源的联系，悬停看联系，点领域名只看这一条线。这是有范围的整理，不是完整的技术史。
- **新增笔记**：数据与监督、RL 方法与成本、推理框架拆解。它们是有范围的学习材料，不是 GPU 性能实测。
- **一起维护的方式**：中英文使用指南、公开路线图、分类反馈、贡献与许可说明；可选的 AI 初审工具不自动批准或发布。

### 记录与升级

继续使用现有的 version-1 进度格式和稳定章节 ID。正常更新网站或 pull 源码不会主动清空同一浏览器、同一站点地址里的记录。网站版本号不等于备份格式版本号。

但这不是云同步。换设备、换浏览器、换站点地址，或清理网站数据时，需要自己导出再导入。未保存的表单不能靠刷新恢复；多个标签同时改同一条记录也不保证事务一致。导出前请确认保存成功，并保留原始备份。**私人备份不要上传到 issue 或仓库。**

### 已知限制

- 当前只有上述四个方向的准备路线；CV、自动驾驶、Jetson、物理仿真和机器人还在提案阶段。
- 读完或收藏一篇不等于掌握知识；没有自动评分、能力预测或 offer 保证。
- 没有账号、云同步、离线缓存或付费服务。浏览器存储不可用时需及时导出，不能把它当成永久存档。
- 自动检查和浏览器抽查不等于全站论文结论都已独立审核，也不等于完成 GPU 或真机实验。

### 正式发布前

1. 复核完整 diff，确认没有私人资料、未授权素材或只打算发在社交平台的草稿；核实已有贡献的许可范围。
2. 跑测试、双语、构建和链接检查；实测收藏、备份导出与导入、中英文切换与手机布局。
3. 完成 PR 审核，处理仍未解决的问题；不把 AI 初审或 CI 当作人工批准。
4. 合并后确认对应提交的 Pages 部署成功，再创建版本标签和 Release，并把此页状态更新为已发布。

检查记录与已知边界见[发布验收](../CONTENT_RELEASE_CHECKLIST.md)；维护者操作见[发布流程](../site/RELEASING.md)。这里不会在这些步骤完成前提前标记发布成功。
