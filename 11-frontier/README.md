# 前沿：先问清楚指的是哪件事

**中文** · [English](README.en.md)

> 阅读时间：约 3 分钟 · 最近审阅：2026-10

模型能不能先预测一个动作的后果，再决定要不要做？多花一些时间推理，答案就会更好吗？能不能看清模型内部是怎样算出答案的？这里围绕这些问题，读论文里的方法、实验和实际例子。

## 为什么单独放一块

这几条研究路线还在发展，同一个名字也可能指不同的方法。比如 Dreamer 用学到的环境模型训练策略，I-JEPA 学的是图像区域的表示，可交互视频模型则要根据操作生成画面。它们都可能出现在“世界模型”的讨论里，但预测目标和用途很不一样。

每个系列先用例子解释方法，再看实验支持了哪些结论。变化快的内容标出时间和来源；标有“待审核”的文章仍是草稿。想了解其中一条路线，可以直接从下面对应的系列开始。

| 你读到的说法 | 先问什么 |
| --- | --- |
| “某某是一个世界模型” | 它预测什么、在什么空间里预测、以什么为条件、拿来做什么？ |
| “AI 在改进它自己” | 改的是哪个对象，谁来决定改动，靠什么信号接受改动？ |
| “测到了 N 倍加速” | 谁测的、用什么单位、有多少人工介入、算力是否同时增长？ |

## 六个系列

1. [世界模型：这个词现在指哪几种东西](world-models/README.md)。从 Dreamer 在想象里训练策略，到 JEPA 预测表示，再到能交互的视频、给机器人当评测器，最后看它们是否真的懂物理。
2. [递归自我改进（RSI）：先问改的是什么](self-improvement/README.md)。区分改权重、改代码、加速研发和自产数据，看验证器为什么决定上限，以及“AI 加速 AI”现在怎么测量。
3. [推理模型与测试时计算：多想一会儿，什么时候有用](test-time-compute/README.md)（待审核草稿）。多采样投票、验证器、长思维链怎样训练出来，以及在同等算力下怎么比较。
4. [用强化学习训练 agent（agentic RL）：从一问一答到多步任务](agentic-rl/README.md)（待审核草稿）。环境和奖励从哪里来、会怎样被钻空子，多步回合里梯度落在哪些 token 上。
5. [机制可解释性：打开模型看它怎么算](interpretability/README.md)（待审核草稿）。探针、叠加、稀疏自编码器和电路，各自能说明什么、说明不了什么。
6. [扩散语言模型（dLLM）：不从左到右，整块去噪](diffusion-lm/README.md)（待审核草稿）。掩码扩散在训练什么、和 BERT 的 MLM 是什么关系，以及并行解码为什么不会自动变快。
